# 📦 Multi-Language Builder

A graphical packaging tool built with Python + tkinter. One-click build executables from source code across **7 programming languages** — no need to memorize complex CLI commands.

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)

![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

## ✨ Features

- 🖥️ **GUI Interface** — No command-line wizardry required
- 🌐 **Bilingual UI** — Switch between English / 中文 on the fly
- 🔧 **7 Languages Supported** — Python, Node.js, Java, C, C++, C#, Go, Rust
- 👁️ **Command Preview & Edit** — See the exact command before execution, tweak if needed
- ✅ **Environment Check** — One-click scan to verify installed toolchains
- 📋 **Real-time Output Log** — Watch build progress as it happens
- ❌ **Cancel Anytime** — Stop a build mid-process
- 📦 **Self-Packaging** — Package the tool itself into a standalone exe
